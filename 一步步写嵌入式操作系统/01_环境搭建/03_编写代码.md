# 二、编写测试代码
参考[[[这篇文章]([[翻译转载]在 QEMU 上实现裸机 ARM32 的 "Hello World" - 知乎](https://zhuanlan.zhihu.com/p/16901864681))]]
我们使用versatilepb作为我们的开发板，而不是书中的s3c2410，和书中的Hello World代码区别只是串口的地址改一下。这款开发板的资料在ARM官网有，[[[这是链接]([Versatile Application Baseboard for ARM926EJ-S User Guide](https://developer.arm.com/documentation/dui0225/d?lang=en))]]

## start.S
```armasm
.global _Reset
_Reset:
 LDR sp, =stack_top
 BL hello_world
 B .
 
```
## linkfile.ld
```cpp
ENTRY(_Reset)
SECTIONS
{
 . = 0x10000;
 .startup . : { start.o(.text) }
 .text : { *(.text) }
 .data : { *(.data) }
 .bss : { *(.bss COMMON) }
 . = ALIGN(8);
 . = . + 0x1000; /* 4kB of stack memory */
 stack_top = .;
}
```

## hello_wrold.c
```c
#define UFCON0 ((volatile unsigned int *)(0x101f1000))

void hello_world(void)

{

    const char *p = "Hello World\r\n";

    while(*p)

    {

        *UFCON0 = *p++;

    };

    while(1);

}
```
## makefile
```makefile
TOOL_PREFIX := arm-none-eabi-

AS  := ${TOOL_PREFIX}as

CC  := ${TOOL_PREFIX}gcc

LD  := ${TOOL_PREFIX}ld

OBJCOPY  := ${TOOL_PREFIX}objcopy

  

CPU := arm926ej-s

QEMU_BOARD := versatilepb

  

PROJECT := hello_world

LD_FILE := linkfile.ld

CLEAN_FILE := ${PROJECT}.o start.o ${ELF_FILE} ${BIN_FILE}

  

all:

    ${AS} -mcpu=${CPU} -g start.S -o start.o

    ${CC} -c -mcpu=${CPU} -g ${PROJECT}.c -o ${PROJECT}.o

    ${LD} -T ${LD_FILE} ${PROJECT}.o start.o -o ${PROJECT}.elf

    ${OBJCOPY} -O binary ${PROJECT}.elf ${PROJECT}.bin

  

clean:

    @rm -rf *.o *.bin *.elf

  

run:

    @qemu-system-arm -M ${QEMU_BOARD} -m 128M -nographic -kernel ${PROJECT}.bin
```
在命令行中运行
```shell
make
```
可以看到已经生成我们所需要的文件了
![](attachments/Pasted%20image%2020251122230729.png)

```shell

```
就可以在qemu中运行我们刚刚编写的代码，然后可以看到有Hello World的输出了
